## Состав стенда

Стенд включает:

- одну виртуальную сеть;
- две подсети в разных зонах доступности;
- два веб-сервера;
- один сервер приложения без публичного IP;
- NAT-шлюз и таблицу маршрутизации для выхода закрытого сервера в интернет;
- целевую группу;
- сетевой балансировщик.

- зона A: `ru-central1-d`;
- зона B: `ru-central1-a`;

- подсеть B: `10.19.2.0/24`;
- порт сервиса: `8027`;
- слово на странице: `cloudlab`;
- число веб-серверов: `2`;
